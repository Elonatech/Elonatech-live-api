# Fonts used to draw certificates on the server

The server has no system fonts on Render, so the certificate renderer bundles its own:

- **Gelasio** (serif; metric-compatible with Georgia) - SIL Open Font License 1.1
- **Arimo** (sans; metric-compatible with Arial) - Apache License 2.0
- **Inconsolata** (monospace, for the certificate ID) - SIL Open Font License 1.1

Licence texts are alongside the font files. All three cover Latin, Latin Extended and Vietnamese,
which includes the dotted letters used in Yoruba and Igbo names.
